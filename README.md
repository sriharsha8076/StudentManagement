# Student Management System

A Python-based Student Management System that supports managing students, enrolling them in courses, and tracking grades.

## Features
- Add and remove students
- Enroll students in courses
- Search students by name
- Grade tracking

## Project Structure
```
StudentManagement/
├── main.py       # Application entry point
├── student.py    # Student model
├── manager.py    # Student manager logic
└── README.md
```

## Usage
```bash
python main.py
```
